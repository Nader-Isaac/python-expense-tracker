# Personal Expense Tracker

A simple Python application for recording and tracking personal expenses.

## Features

- Record personal expenses.
- Organize expense information.
- Display expense records.
- Practice basic financial tracking using Python.

## Requirements

- Python 3.x

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python "expenes tracker.py"
   ```
